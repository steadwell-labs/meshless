Steadwell Labs claims these as unregistered marks for the purpose of identifying
this protocol and its implementations.

## What you may do without asking

- State truthfully that your implementation implements the Meshless Protocol, or
  conforms to MLP/1, and refer to the specification by name.
- Use the marks in descriptive text, documentation, talks, articles, and
  comparisons, provided the reference is accurate and not misleading.
- Use the marks to refer to this repository and its specification.
- Ship a fork or derivative of this code under a different name.

## What requires permission

- Naming a product, company, or service "Meshless" or a confusingly similar name.
- Using the marks in a domain name, logo, or app icon for your own product.
- Implying endorsement, certification, or affiliation that does not exist.
- Describing an implementation as "certified" or "official" without a written
  agreement.

## Conformance claims

Any implementation may claim conformance to MLP/1 Draft 00 if it passes the
published conformance suite in `tests/`. A conformance claim must state the
version it refers to, and must not imply more than the suite tests. Because
Draft 00 has no audit and no independent implementations yet, claims of
production readiness based on this repository are not supported by the project.
